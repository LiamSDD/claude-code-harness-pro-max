# Kimi Code tool mapping

| Action | On Kimi Code |
| --- | --- |
| Ask the user | `AskUserQuestion` |
| Track tasks | `TodoList` |
| Dispatch a subagent | `Agent` with `subagent_type` `coder` (implementation, review), `explore` (read-only search) or `plan` (design) |
| Invoke a skill | `Skill` |
| Files, shell, search, web | `Read`, `Write`, `Edit`, `Bash`, `Grep`, `Glob`, `FetchURL`, `WebSearch` |
